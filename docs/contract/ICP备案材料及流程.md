# ICP 备案材料及流程说明

## 1. 是否需要 ICP 备案

如果使用阿里云中国内地节点 ECS，并通过域名向互联网开放访问，则需要完成ICP备案。

不需要 ICP 备案的常见情况：

- 服务器部署在中国香港、海外节点等非中国内地地域。
- 系统仅在内网、VPN、专线环境中使用，不对公网域名开放。

注意：

- 使用阿里云中国内地服务器时，阿里云作为接入服务商提供备案服务。
- 如果服务器在其他云厂商，应在实际接入服务商处备案。
- 即使主体已在工信部备案，若网站迁移到阿里云中国内地服务器，通常仍需在阿里云办理新增接入。

## 2. 建议备案主体

建议使用：**企业单位备案**。

不建议使用个人备案，原因：

- 个人备案一般适用于个人非经营性内容展示。
- 本项目面向企业业务使用，涉及公司、供应商、招标、项目管理等企业属性内容。
- 使用个人备案可能导致网站内容与备案主体性质不一致，增加驳回或后续核查风险。

## 3. 备案前准备

| 准备项 | 说明 |
|---|---|
| 阿里云账号 | 用于备案申请和后续备案维护；一个阿里云账号最多只能有一个备案主体 |
| 域名 | 需完成域名注册、实名认证，并确认域名支持 ICP 备案 |
| 服务器 | 需准备阿里云中国内地节点服务器；备案账号和服务器账号不同则需服务码授权 |
| 备案资料 | 企业或个人主体资料不同，按备案主体准备 |
| 管局规则 | 各省通信管理局要求不同，需按备案所在省份确认补充材料 |
| 前置审批 | 新闻、出版、药品医疗器械、金融、宗教等特殊内容需先办前置审批 |

## 4. 企业单位备案材料

企业备案建议优先准备以下材料：

| 材料 | 是否常用 | 说明 |
|---|---|---|
| 主办单位证件 | 必备 | 营业执照等单位资质证件原件照片或彩色扫描件 |
| 主体负责人证件 | 必备 | 通常为法定代表人身份证；部分省份要求主体负责人必须为法人 |
| 网站负责人证件 | 必备 | 网站负责人身份证；若与法人不同，可能需要授权书 |
| 域名证书 | 视省份要求 | 用于证明域名注册信息合规 |
| 授权书 | 视情况 | 主体负责人或网站负责人非法定代表人时，部分省份要求提供 |
| 网站建设方案书 | 视省份要求 | 广东、湖北等省份在域名较多等场景可能要求；湖南部分新增备案场景要求 |
| 组网方案建设书 | 视省份要求 | 包含网站服务内容、栏目说明、部署架构、安全制度、承诺声明等 |
| 手持单位证件照片 | 视省份要求 | 部分省份要求网站负责人上传手持证件照片 |
| 网站备案承诺书 | 视省份要求 | 如河南省等可能要求 |
| 前置审批承诺书 | 视内容 | 若备案内容含敏感行业关键词但实际不涉及，可能需提供承诺书 |
| 变更证明 | 视情况 | 企业名称发生变更时提供 |
| 经营性说明书 | 视省份要求 | 如四川省对含“经营性”字样的单位名称、经营范围、网站名称或备注可能要求 |

## 5. 个人备案材料

如坚持使用个人主体备案，通常需准备：

| 材料 | 是否常用 | 说明 |
|---|---|---|
| 个人身份证件 | 必备 | 中国内地居民为身份证；港澳台或其他国家/地区按阿里云要求提供对应证件 |
| 域名证书 | 视省份要求 | 部分省份管局要求提供 |
| 手持个人证件照片 | 视省份要求 | 部分省份要求互联网信息服务负责人手持身份证或户口本照片 |
| 网站建设方案书 | 视省份要求 | 广东、湖北、湖南等部分场景可能要求 |
| 暂住证或居住证 | 视省份要求 | 如福建省对户籍地与备案地不一致可能要求 |
| 组网方案建设书 | 视省份要求 | 包含服务内容、组网、安全制度、承诺声明等 |
| 网站备案承诺书 | 视省份要求 | 如河南省等可能要求 |
| 前置审批承诺书 | 视内容 | 若涉及需前置审批关键词但实际不涉及，可能需提供 |

## 6. 材料格式与有效期要求

| 项目 | 要求 |
|---|---|
| 图片格式 | JPG、JPEG、PNG、GIF |
| 图片大小 | 每张图片 200 KB - 4 MB |
| 清晰度 | 证件信息、边框、文字必须清晰完整 |
| 证件照片 | 应上传最新证件原件拍照或彩色扫描照片 |
| 不建议 | 复印件照片、黑白扫描件、翻拍屏幕照片、电子证件、二次扫描照片 |
| 证件有效期 | 自提交备案订单当日起，证件剩余有效期通常应不少于 3 个月 |
| 授权书/证明 | 多数授权书及相关证明一般要求办理日至提交日不超过 3 个月；个别省份另有要求 |

## 7. 阿里云 ICP 备案流程

### 步骤 1：进入阿里云 ICP 代备案管理系统

登录阿里云账号，进入 ICP 代备案管理系统，点击“开始备案”。

### 步骤 2：填写基础信息

系统会校验：

- 备案主体类型。
- 域名是否满足备案要求。
- 是否有可备案的阿里云中国内地服务器。
- 备案账号与服务器账号是否一致；不一致时需备案服务码。

### 步骤 3：填写主办者信息

企业备案填写公司主体信息，通常包括：

- 企业名称。
- 统一社会信用代码。
- 营业执照信息。
- 主体负责人信息。
- 证件地址、通信地址、联系电话、邮箱等。

个人备案填写个人真实身份信息。

### 步骤 4：填写网站信息

MEMPAS 可按以下方向填写：

| 项目 | 建议填写 |
|---|---|
| 网站名称 | 与企业和系统用途一致，避免使用夸大、经营性、新闻、金融等敏感表述 |
| 网站用途 | 企业内部机电材料查询、报价比价、供应商管理、采购数据分析 |
| 网站内容 | 工作台、物料主数据、供应商管理、采购价格导入、招标比价分析等 |
| 域名 | 客户正式域名 |
| 接入信息 | 阿里云 ECS 公网 IP、服务器实例 |

### 步骤 5：上传资料及真实性核验

按系统提示上传主体证件、负责人证件、域名证书、授权书等材料，并按要求完成真实性核验。

### 步骤 6：提交备案订单

提交前需仔细核对：

- 主体信息是否与证件一致。
- 域名实名信息是否一致。
- 网站名称和网站内容是否与实际页面一致。
- 手机号、邮箱是否可接收审核通知。

### 步骤 7：阿里云初审

提交后由阿里云进行初审。官方说明通常为 1-2 个工作日内完成初审并反馈结果。初审通过后，阿里云会提交至省通信管理局审核。

### 步骤 8：工信部短信核验

按短信提示在工信部备案系统完成短信核验。短信核验未完成会影响后续管局审核。

### 步骤 9：管局审核

短信核验完成后，由备案所在地省通信管理局最终审核。审核通过后，备案结果会发送至手机和邮箱，也可在阿里云 ICP 代备案管理系统查看进度。

### 步骤 10：备案后处理

备案成功后：

- 将域名解析到 ECS 公网 IP。
- 开通网站访问。
- 在网站首页底部添加 ICP 备案号。
- ICP 备案号应链接至工信部备案查询网站。
- 网站/App 开通后 30 天内，需完成公安联网备案。
- 若网站或 App 提供经营性有偿信息或服务，ICP备案后还需评估是否办理经营性 ICP 许可证。

## 8. 备案内容建议

备案时建议使用更准确、低风险的企业内部管理表述。

可参考：

> 本网站为企业内部机电材料采购数据管理与比价分析系统，主要提供物料主数据管理、供应商资料管理、历史采购价格查询、报价文件导入、招标报价横向对比、采购数据统计分析等功能。网站不面向公众发布新闻资讯，不提供金融、医疗、出版、药品销售、宗教等需要前置审批的互联网信息服务。
