# 阿里云资源清单及价格

## 1. 系统部署假设

MEMPAS 正式部署按四层资源规划：

- 应用层：前端、后端部署在 ECS 服务器。
  - 前端：Vue 3 + Vite，生产环境由 Nginx 提供页面访问。
  - 后端：Python 3 + FastAPI + Uvicorn，提供业务 API、文件上传、比价分析等服务。
- 数据层：数据库使用阿里云 RDS MySQL。
- 存储层：文件存储服务使用阿里云 OSS，用于保存报价单、招标文件、OCR 上传文件及解析过程文件。
- 解析层：大语言模型 / 文档解析服务待定，用于 PDF、图片、扫描件结构化识别；服务器本地不做大模型推理。

初期容量目标：

- 在线用户：约 20 人起步，可支撑到 30-50 人小规模使用。
- OCR / 文件识别：起步按 1-3 次/分钟估算；升级配置可支撑 5-10 次/分钟。
- 单文件上传：通常为 Excel、PDF、图片，建议 Nginx 限制单文件 100 MB。
