# 研发范围及功能描述


## 1. 建设目标

乙方根据甲方提供的历史采购数据、报价文件样例、招标比价业务规则及阶段性反馈，研发一套面向机电材料采购场景的查询、导入、分析和比价辅助系统。

系统主要用于支持甲方进行物料主数据维护、供应商资料管理、历史采购价格查询、采购报价导入、招标报价横向对比、供应商辅助推荐和采购数据统计分析。系统定位为甲方内部业务辅助工具，不作为公开交易平台、招投标交易平台或财务结算系统。

## 2. 技术实现范围

| 层级 | 研发内容 |
|---|---|
| 前端应用 | 基于 Vue 3、Vite、Ant Design Vue 实现后台管理式 Web 界面 |
| 后端服务 | 基于 Python 3、FastAPI 实现业务接口、数据处理、文件识别任务流转和分析计算 |
| 数据存储 | 支持用户、项目、物料、供应商、报价、配置等结构化数据存储 |
| 文件处理 | 支持报价文件、招标文件、PDF、图片等文件上传及解析流程接入 |
| AI 能力接入 | 支持接入外部大语言模型 / 文档解析服务进行辅助识别，具体模型供应商可按部署阶段配置 |

## 3. 功能模块范围

### 3.1 登录与基础框架

乙方提供系统登录页面、主框架布局、侧边菜单、顶部栏、路由跳转和基础访问控制入口。

一期系统以管理员使用为主，支持登录后访问各业务页面。路由级细粒度权限控制、复杂角色权限体系、组织架构权限隔离等不作为本期研发范围。

### 3.2 工作台

乙方提供工作台页面，用于展示系统整体数据概览，包括：

- 物料、供应商、项目、报价等核心数据摘要。
- 采购数据统计卡片。
- 按项目、品类、金额等维度展示的数据可视化图表。
- 品类、供应商等维度的概览分析。

工作台用于辅助查看整体数据状态，统计结果以系统已导入数据为基础。

### 3.3 物料主数据管理

乙方提供物料主数据管理功能，包括：

- 物料列表展示、分页、查询和筛选。
- 物料新增、编辑、删除、查看。
- 按专业、品类、子类等维度组织物料数据。
- 保存物料名称、规格型号、材质、单位、品牌、参考价格、合理史低等字段。
- 支持物料名称、规格、品类等基础标准化处理。
- 支持按品类维护扩展属性结构，用于后续比价匹配和差异说明。

甲方自有物料编码体系如尚未最终确认，系统可预留编码字段，后续由双方根据甲方编码规则再行对接。

### 3.4 供应商管理

乙方提供供应商资料管理功能，包括：

- 供应商列表展示、分页、查询。
- 供应商新增、编辑、删除、查看。
- 维护供应商名称、简称、联系人、电话、经营品类、中标次数、合作评分等信息。
- 基于已导入报价和历史合作信息，提供供应商评分及辅助对比能力。

供应商评分为辅助参考，不替代甲方内部采购决策、评审流程或合规审批流程。

### 3.5 项目管理

乙方提供项目管理功能，包括：

- 项目列表展示、查询。
- 项目新增、编辑、删除。
- 维护项目名称、编号、地点、状态、备注等基础信息。
- 支持项目与报价记录、招标比价任务关联。

复杂项目流程审批、合同管理、付款管理、采购执行闭环等不作为本期研发范围。

### 3.6 报价管理与数据导入

乙方提供报价记录管理及批量导入能力，包括：

- 报价记录列表、查询、筛选。
- 报价新增、编辑、删除、查看。
- 保存物料、供应商、项目、含税单价、不含税单价、税率、数量、总价、品牌、备注等信息。
- 支持 Excel / CSV 报价数据导入。
- 支持按品类模板解析历史报价数据。
- 导入过程中自动识别物料和供应商，减少重复数据录入。
- 对新增或未分档品牌提供品牌档位维护入口。

数据导入结果受原始文件格式、字段完整度和数据质量影响。对于格式差异较大或缺失严重的文件，系统提供辅助解析和人工确认能力，乙方不承诺所有非标准文件均可完全自动入库。

### 3.7 文件识别与 OCR 辅助解析

乙方提供 PDF、图片、扫描件等文件上传及识别任务流程，包括：

- 招标文件、报价文件上传。
- 文件接收、任务创建、识别状态展示。
- PDF 页面渲染、分页处理、逐页识别进度展示。
- 识别结果整理、预览和确认入口。
- 支持接入外部大语言模型 / 文档解析服务进行结构化识别。

识别结果作为辅助录入结果，需由甲方业务人员根据原始文件进行复核。因原始文件模糊、扫描倾斜、表格跨页、内容缺失、模型服务波动等原因导致的识别误差，应通过人工确认、修正或重新上传处理。

### 3.8 招标比价分析

乙方提供招标比价分析核心功能，包括：

- 按项目、品类、供应商配置比价任务。
- 选择 2 家及以上供应商参与横向比价。
- 根据导入报价生成横向对比矩阵。
- 展示物料、规格、历史均价、合理史低、供应商报价、总价、偏差率、最低价标记等信息。
- 对报价偏差进行颜色标识，默认区分正常、需关注、异常等状态。
- 生成供应商报价汇总、平均偏差、推荐参考等辅助信息。

比价结果以系统已导入数据和配置规则为基础，仅作为采购分析辅助，不构成自动定标、自动中标或采购审批结论。

### 3.9 单项价格比对与品类统计

乙方提供单项价格比对和品类统计功能，包括：

- 按品类、子类、新报价金额进行价格比对。
- 计算合理史低、历史均价、中位价、P10/P90、偏差率等指标。
- 按品类输出价格分布、样本数量、变异系数等统计信息。
- 对历史数据较少的品类，系统可展示统计结果，但结果仅供参考。

合理史低等指标基于甲方提供并导入系统的历史数据计算。历史样本不足、报价口径不一致或数据质量不足时，统计结果可能存在偏差。

### 3.10 邀标建议

乙方提供邀标建议辅助功能，包括：

- 上传招标文件并识别材料清单。
- 根据系统内供应商资料、历史报价和品类匹配情况，生成供应商推荐结果。
- 支持保存邀标推荐结果。
- 支持查看和跟踪已保存的邀标建议记录。

邀标建议为系统辅助推荐，不替代甲方供应商准入、合规审核、招采审批或最终采购决策。

### 3.11 系统设置

乙方提供系统基础配置能力，包括：

- 评分权重配置。
- 报价偏差阈值配置。
- 品牌档位映射维护。
- 品类扩展属性配置。

配置项用于支撑系统分析规则，具体业务规则由甲方确认后录入或调整。

### 3.12 导出能力

乙方提供部分数据导出能力，用于业务查看和线下归档。导出范围以系统已实现页面和接口为准。

标准化比价报告 Excel 模板、复杂审批格式报表、客户指定格式深度定制报表等，可作为后续迭代或另行约定范围。

## 4. 数据范围

本期系统主要围绕甲方已提供或后续导入的机电材料采购数据开展建设，品类包括但不限于：

- 电气：桥架、母线槽、配电箱等。
- 给排水：阀门、不锈钢管、水箱、潜水泵等。
- 暖通：风口风阀、风机盘管、空调泵等。

部分品类历史数据样本较少，系统可支持录入、保存和横向比价，但统计分析结果仅作为参考。

## 5. 本期不包含或仅作预留的内容

为避免合同范围扩大，以下内容不作为本期必须交付范围，除非双方另行书面确认：

- 完整的多角色、多组织、细粒度权限控制体系。
- 用户管理后端完整 CRUD、组织架构、部门权限管理。
- 操作日志后端完整记录、检索和审计报表。
- 财务结算、合同付款、发票管理、ERP 对接。
- 自动定标、自动中标、采购审批流。
- 所有非标准 PDF、扫描件、图片的完全自动准确识别。
- AI 报价对齐复核、字段纠错建议和用户确认落库的完整闭环。
- 配电箱 BOM 元器件级拆分导入；当前按客户反馈以横向比价为主。
- 标准 Excel 比价报告的复杂格式定制。
- 高并发多机部署、异步 Worker 队列、Redis 队列、数据库迁移脚本等扩展架构。
- 与第三方系统的接口集成，包括 ERP、OA、财务系统、电子招投标平台等。

## 6. 验收口径建议

建议按以下方式进行验收：

- 系统可正常登录并访问主要页面。
- 物料、供应商、项目、报价等基础数据可新增、编辑、查询。
- 可导入符合模板要求的 Excel / CSV 报价数据。
- 可上传 PDF / 图片文件并形成识别任务和识别结果预览。
- 可基于已导入的项目、品类、供应商数据生成横向比价矩阵。
- 可查看工作台统计、单项比价、品类统计、供应商辅助评分等分析结果。
- 系统配置项可正常读取和保存。

验收数据以双方确认的样例文件、样例账号、样例项目和样例供应商为准。对于非样例格式或质量明显偏低的文件，应纳入后续优化或人工处理范围。
