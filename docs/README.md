### v2 主要变更（2025-05-19）

基于一建用户反馈做了以下关键调整：

- **比价基准**：从历史均价/中位价改为「合理史低」（IQR 过滤后最小值）
- **偏差机制**：取消四级报警（green/yellow/red/blue），改为偏差值 + 色标（黄色 5-10%，红色 >10%）
- **异常值检测**：取消修正 Z 分（Modified Z-score）
- **品牌维度**：品牌作为匹配项参与比对，按档位（一/二/三档）区分，不区分具体品牌
- **配电箱**：不按整箱比对，按元器件级别拆分比较
- **核心页面**：新增「横向对比矩阵」（招标比价分析的主交互界面）
- **工作台**：新增树状热力图、气泡图、数据流/待办

### v2.1 主要变更（2026-05-19）

后端 P0/P1 全部实现，版本号升至 v0.2.0：

- **合理史低算法**：IQR 过滤后最小值，响应携带来源项目/日期
- **横向对比矩阵**：`POST /api/analysis/bid-matrix` 正式上线
- **品牌档位**：新表 + CRUD API + 导入时未知品牌弹窗
- **供应商评分**：权重短键（price/history/completeness/brand/commercial），品牌维度改用档位命中率
- **物料去重**：按 (category, standard_name, spec) 去重，导入不再重复入库
- **OCR 提取流程**：`/api/intake/upload` + 异步 job polling + `ExtractionEditor` 人工核对
- **认证**：`POST /api/auth/login`（JWT，环境变量 `JWT_SECRET`）
- 待实现：配电箱 BOM 拆分、用户/日志 API、路由权限守卫 → 见 [spec/FUNCTIONAL.md §12](spec/FUNCTIONAL.md)
