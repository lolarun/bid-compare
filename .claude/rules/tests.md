# 测试与验收规则

- 单元测试验证局部契约，snapshot replay 验证确定性，fresh E2E 验证真实模型链路；三者不得互相冒充。
- 测试通过必须报告实际执行的测试文件、通过数、失败数和被排除项；不得主动排除直接相关测试后声称全绿。
- replay 缓存 miss、失败目标页和截断必须使测试失败，禁止静默跳页造成假绿。
- 标准答案先审计来源。Excel 内部自洽不等于 PDF 字面真值；OCR 派生字段不得循环验证 OCR。
- 识别指标至少分行召回、precision、字段 present/exact、金额闭环和质量等级。
- 比价 E2E 至少覆盖：多 submission 身份、顺序串位、局部冲突隔离、pending 不参与总价、页面与导出一致。
- 回归夹具不得包含密钥、个人数据或不可解释的临时输出。
