# Archived May 2026 demo bundle

This directory preserves the May 2026 scripted demo, prototype pages, screenshots,
and generation scripts as one point-in-time bundle. It describes retired routes,
ports, UI structure, and recognition behavior. It is not maintained and must not
be used as current product documentation; use `docs/spec/` instead.

The scripts retain their original relative paths for provenance and are not
expected to run from this archive location without manual adjustment.
