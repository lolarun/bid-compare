# Archived customer feedback evidence

These files preserve dated, source-faithful customer feedback and local test
observations. They are evidence for requirement provenance, not current product
specifications or an active backlog. Current behavior and open decisions live in
`docs/spec/`; implementation planning lives at the repository root.

Original wording is retained. When a conclusion here conflicts with current
code or specs, the dated record remains historical and must not override current
verified behavior.
